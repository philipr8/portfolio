# philipradeff — portfolio

Personal site for Philip Radeff, served by GitHub Pages from the root of `main`.

- `index.html` — the site. Hand-written HTML/CSS/JS, no build step, no frameworks.
- `styles.css` / `main.js` — styles and behaviour (WebGL aurora shader, scroll-expanding hero, reveals, phone mockup).
- `game.html` — *Beyond the Wall*, a canvas endless runner.
- `assets/` — images. `Philip_Radeff_Resume.pdf` — the résumé linked from the site.

Deploy: push to `main`. Preview locally: `python3 -m http.server 8000` and open http://localhost:8000.
